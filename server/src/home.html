How it works

  1. Build

    Create the app with Claude Code, Cursor, Codex or your preferred coding agent.

  2. Deploy

    Tell the agent to deploy it with Brod.

  3. Secure

    Brod handles identity, access, data, secrets and versions.

  4. Share

    Your team opens the private address and signs in.

Works with the agent you already use.

Brod is an MCP server, so any agent that speaks MCP can deploy, read logs and roll back. Scripts and CI can use the REST API.

  • Claude Code
  • Cursor
  • Codex, VS Code and other MCP agents
  • REST API

For example, in Claude Code:

claude mcp add --transport http brod {{ORIGIN}}/mcp

Then sign in when the browser opens. Other agents use the address {{ORIGIN}}/mcp.

Brod decides who can open each app before a request reaches it. Agents can ship, but opening an app up stays a human decision.

Read the security model

  • Private by default. A new app is open only to its owner and admins.
  • People confirm widening access. Sharing more widely, inviting someone or deleting an app waits for a person to confirm.
  • Staging first. Updates to a live app go to a staging address unless you say otherwise.
  • Secrets stay secret. Encrypted at rest and never readable through the API.
  • One place for every app. Remove someone from the workspace and they lose access everywhere on their next request.
  • Every deploy is recorded. Versions, access changes and refusals are in each app's log.

Questions

What kind of apps can I deploy?

Web apps: static files (HTML, JavaScript, any built front end) and, if needed, a small server script in _worker.js that answers requests and reads the database and secrets. Brod is made for internal tools, not for large public sites.

Is Brod a replacement for Vercel?

No. General-purpose platforms give you full control over frameworks and infrastructure. Brod is narrower: it runs internal apps and gives them sign-in, permissions, data and secrets without setup.

Does Brod generate the app?

No. Your coding agent writes the app. Brod runs it and gives it what it needs in production.

Which coding agents work with Brod?

Any agent that supports remote MCP servers, including Claude Code, Claude Desktop, Cursor, Codex and VS Code. There is also a REST API.

Can I deploy private internal tools?

Yes, that is the default. Apps start private, and you choose who else can open them: named people, groups, an email domain or the whole workspace.

Does every app need to implement authentication?

No. People sign in once with an emailed link or Google, and Brod checks access before a request reaches the app. The app asks Brod who the person is with one call, or reads it from request headers.

Can Brod be self-hosted?

Yes. Brod is open source under AGPL-3.0. It is one server and a Postgres database, and runs with Docker Compose. See the repository.
